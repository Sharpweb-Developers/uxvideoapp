# uxvideoapp
UX Interview Emotion &amp; State Analysis:  Automated detection of the gap between what users say and what they actually feel — using ML-driven analysis of verbal and non-verbal signals in UX research sessions.
The problem

Traditional UX research relies on interviews: a researcher asks questions, a user answers, and the results are captured as quotes, NPS scores, and behavioral notes. This method has a fundamental limitation — users say one thing and feel another. Verbal answers reflect a conscious, socially acceptable response, while non-verbal signals (facial expressions, voice, pauses) reveal a person's real emotional state before they've had time to consciously frame it.

Researchers currently spend significant time manually reviewing session recordings and subjectively interpreting these reactions — a slow, inconsistent, and hard-to-scale process.

What this project does

This project explores automating part of that analysis using machine learning: extracting and correlating verbal (transcribed speech, sentiment, word choice) and non-verbal (facial expression, vocal tone/prosody, response latency/pauses) signals from UX interview recordings, in order to:

Detect discrepancies between stated satisfaction and observed emotional state
Flag moments of hesitation, discomfort, or false positivity that a manual review might miss
Provide researchers with an objective, data-backed layer to complement traditional qualitative analysis
Reduce the time spent manually reviewing raw session footage.
